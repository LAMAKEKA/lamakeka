# Integración RFID XRS2i — Plan de Implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Integrar el lector XRS2i (HID mode) al módulo Manga: captura de EID → ficha/alta de animal, con sesiones de lectura y soporte offline.

**Architecture:** Web-first con transporte HID (keyboard wedge). El EID entra por un campo de captura siempre enfocado, se valida, y se procesa vía `POST /api/rfid/scans` (online) o cola IndexedDB (offline) con sincronización idempotente.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Supabase (PostgreSQL + Auth + RLS), IndexedDB (sin deps).

## Global Constraints

- Reutilizar estilos existentes: variables `--color-campo`, `--color-pampa`, `--color-cuero`, `--color-tierra`, `--color-arpillera`, clase `.form-label`, `INPUT_STYLE` existente.
- No romper módulos existentes (hacienda, potreros, insumos, etc.).
- EID: 15 dígitos ISO 11784/85; normalizar con `strip non-digits`.
- Sin dependencias nuevas en package.json.
- `"use client"` en hooks/componentes de cliente; route handler server-side con `runtime = 'nodejs'`.
